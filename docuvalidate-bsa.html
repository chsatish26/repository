  • Version controlled

1

📤 Document Upload & Ingestion

API Gateway + S3

User uploads governance document (MDD, Deployment Plan, Monitoring Report) via secure web portal.

  • Apigee validates request & authenticates via FM SSO Ping
  • Document stored in S3 with KMS encryption
  • S3 event notification triggers EventBridge
Input

PDF/DOCX Document, User Credentials

Output

Document ID, S3 URI, Metadata JSON

2

⚡ Workflow Orchestration

Step Functions + EventBridge

AWS Step Functions state machine orchestrates the entire validation pipeline with error handling, retry logic, and parallel execution capabilities.

  • EventBridge initiates Step Functions execution
  • State machine manages agent invocation sequence
  • Built-in error handling with exponential backoff
Input

S3 Event, Document Metadata

Output

Execution ARN, Workflow State

3

📑 Section Mapping

ECS Fargate + Bedrock

Parse document structure and map existing content to standardized governance sections using semantic analysis.

  • Extract text, tables, headers from document
  • Use Bedrock (Claude) for semantic section matching
  • Validate content integrity (no loss, no additions)
  • Generate content hashes for traceability
Input

Raw Document (S3), Governance Template Schema

Output

Mapped Document JSON, Section Index, Integrity Check Result

4

📋 Governance Rules Retrieval

Lambda (Parallel)

Fetch validation rules from external governance systems in parallel with section mapping.

  • Query Internal Policy Repository
  • Fetch rules from Risk Works System
  • Retrieve regulatory requirements
  • Normalize into machine-readable validation criteria
Input

Document Type, Regulatory Context

Output

Normalized Governance Ruleset JSON

5

🔍 Compliance Evaluation

ECS Fargate + Bedrock

Execute rule-based validation comparing each mapped section against governance requirements.

  • Load applicable rules per section
  • Execute validation checks: Presence, Completeness, Consistency, Duplication
  • Record findings: PASS, WARNING, FAIL
  • Use Bedrock for semantic content analysis
Input

Mapped Sections, Governance Ruleset

Output

Compliance Assessment JSON, Gap List, Duplicate Findings

6

📊 DocuScorer - Classification

Lambda

Calculate compliance score and classify document based on weighted rule coverage.

  • Apply scoring algorithm: Section Score = Σ(rule_weight × result)
  • Classify: ✅ Fully Compliant (≥95%) | ⚠️ Partial (70-95%) | ❌ Non-Compliant (<70%)
  • Generate section-level breakdown
Input

Evaluation Results, Scoring Weights

Output

Overall Score, Classification, Section Scores

7

💡 Recommendation Generation

ECS Fargate + Bedrock

Analyze evaluation results to identify gaps and generate actionable improvement recommendations.

  • Identify specific governance gaps per section
  • Suggest content reorganization (without modification)
  • Generate prioritized actionable recommendations
  • Reference original content locations
Input

Evaluation Results, Original Mapped Content

Output

Gap Analysis, Reorganization Suggestions, Recommendations

8

📄 Report Generation

Lambda

Aggregate all agent outputs into a comprehensive, audit-ready governance validation report.

  • Compile: Score, Classification, Gaps, Duplicates, Recommendations
  • Generate multiple formats: PDF, JSON, Dashboard-ready
  • Include full audit trail with timestamps
Input

All Agent Outputs, Report Template

Output

PDF Report, JSON Data, Dashboard Payload

9

📬 Delivery & Notification

S3 + SNS + Dashboard

Store final reports and notify stakeholders of completion.

  • Store reports in S3 (Reports bucket)
  • Send SNS notification to user
  • Update governance dashboard
  • Archive execution logs for audit
Input

Final Report, User Contact Info

Output

Report URL, Notification Sent, Dashboard Updated
